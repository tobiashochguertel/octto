## Quick Reference

### When to Use Octto

✅ **Ideal for:**
- Exploring multiple design approaches
- Complex technical decisions with trade-offs
- Requirements gathering and clarification
- Architecture planning and system design
- Feature specification and planning

❌ **Less suitable for:**
- Simple code fixes or debugging
- One-off questions without exploration
- Tasks requiring immediate code execution
- Very small scope decisions

### Basic Usage Pattern

1. **Start with a clear request**: "Design a user authentication system"
2. **Answer questions in the browser UI**: Click options, provide text input as needed
3. **Review parallel exploration branches**: See different approaches simultaneously
4. **Iterate on answers**: Go back and change responses if needed
5. **Get the final design document**: Review and approve the generated plan

### Key Concepts

- **Parallel Branches**: Octto explores 2-4 approaches simultaneously
- **Interactive Questions**: 15 different question types for structured input
- **Multi-Agent System**: Specialized agents for bootstrapping, probing, and orchestration
- **Visual Feedback**: Real-time progress tracking and answer visualization
